# Security policy

Do not include credentials, private media, account details, signed URLs, or
other sensitive information in an issue.

Report a vulnerability through GitHub private vulnerability reporting for this
repository. If that option is not yet available, open a public issue asking the
maintainer to provide a private contact channel; include no vulnerability
details in that issue.

Only the latest release and the current `main` branch receive security fixes.
There is no guaranteed response time, but maintainers will acknowledge a
complete private report as soon as practical.

LinguaRelay must only be used with media you are authorised to process. Local
job data belongs outside the repository in an owner-only directory.
